# まちまど — バーチャル海外散歩エージェント

「パリで朝市と古い路地を30分」のように頼むと、AIエージェントが **本当にストリートビューで歩ける** 散歩コースを自分で組み立て、
現地のひとこととクイズ付きで案内します（クイズは一時的に停止中）。

## 対象ユーザーと課題
- 海外に行きたくても、時間・お金・体力の事情でなかなか行けない人
- 旅行の下見や、語学・地理の学びを「行った気分」で楽しみたい人

地図アプリで名所を検索しても「点」しか見えず、街を歩く体験にはなりません。
一方で AI にコースを考えさせると、実在しない場所やストリートビューのない地点が混ざりがちです。

## ソリューションと特徴
- **計画 → 確認 → 差し替え** を自律的にくり返すエージェント（Gemini の関数呼び出し）
  - `search_places`（Places API）で実在と位置を確認
  - `check_street_view`（Street View metadata）で屋外画像の有無を確認し、なければ半径を広げる／別候補に差し替える
  - `wikipedia` で事実を確認してから解説を書く
  - `add_stop` は確認済みの地点（pano_id）しか受け付けない＝「歩けない地点」を構造的に排除
- **可観測性**：エージェントの考え・道具の呼び出し・結果を「足あと」として画面にリアルタイム表示。
  同じ内容を trace_id 付きの構造化ログで Cloud Logging に記録
- **安全性**：道具の結果（Web の文章）に含まれる指示には従わない、道具の呼び出し回数・手数の上限、IP ごとの利用回数制限、入力長の制限
- 立ち寄り先ごとに現地語のひとこと（読み上げ付き）、最後に散歩の内容から4択クイズ

## アーキテクチャ
ブラウザ（Maps JavaScript API / Street View） ⇄ Cloud Run（FastAPI）⇄ Gemini API（関数呼び出し）
Cloud Run から Places API・Street View metadata・Wikipedia REST を道具として呼び出し、途中経過を NDJSON でストリーミング。
GitHub に push すると GitHub Actions がイメージを作り Artifact Registry 経由で Cloud Run にデプロイ。

## 動かし方
環境変数 `GEMINI_API_KEY`, `MAPS_API_KEY` を設定して `uvicorn main:app --port 8080`。
